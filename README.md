# MyQuizApp

## 作成したJSONファイルから、ランダムに問題を出題する学習アプリです。

- 選択肢から解答する4択問題と、単語カードのようにめくって解答するフラッシュカードがあります。</li>
- 問題に⭐スターをつけることで、特に練習したい問題を繰り返し解くことができます。</li>
- 4択問題で不正解になった問題、フラッシュカードで「わからなかった」を選んだ問題は自動的に🔥弱点として登録され、「弱点集中モード」で繰り返し復習できます。正解（または「わかった」を選択）するとその問題は弱点から自動的に外れます。</li>
- 日々の学習記録を保存することができます。</li>
- ⭐スター、🔥弱点、学習記録のデータはLocalStorageに保存されます。
